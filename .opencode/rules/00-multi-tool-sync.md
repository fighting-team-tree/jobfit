# AI Tools Synchronization Rule (다중 AI 툴 동기화 규칙)

현재 워크스페이스에는 다양한 AI 도구들을 위한 개별 설정 폴더가 존재합니다:
- `.agent/`: 메인 AI 코딩 어시스턴트용 (우선 기준)
- `.claude/`: Claude Code CLI 용
- `.gemini/`: Gemini CLI 용
- `.codex/`: Codex CLI 용
- `.opencode/`: OpenCode 용

## ⚠️ 동기화 원칙 (필독)

1. **독립 유지**: 각 폴더의 규칙이나 스킬은 툴의 특성에 맞게 구성되어 있으므로 무조건 하나로 병합(Merge)하지 않고 독립적으로 유지합니다.
2. **변경 시 크로스체크 의무화**:
   - AI 에이전트가 위 폴더들 중 한 곳의 규칙(Rule), 스킬(Skill), 컨텍스트를 수정하거나 추가할 때는 **반드시 다른 툴의 폴더들에도 동일/유사한 설정이 있는지 확인**해야 합니다.
   - 변경 사항이 한 쪽에만 반영되어 불일치가 발생할 것으로 예상되면, **무단으로 타 툴 폴더를 수정하지 말고 사용자에게 먼저 질문하여 방향을 결정**해야 합니다.
   - 예시: *"`.agent/rules/01-auth.md`를 수정했습니다. `.claude/` 등 다른 툴 폴더에도 해당 규칙을 업데이트 할까요?"*
3. **기준(Source of Truth)**: 모호한 상황이나 충돌 발생 시, 기본적으로 `.agent/` 폴더 내의 내용을 최신화된 우선 기준(Source of Truth)으로 취급합니다.
