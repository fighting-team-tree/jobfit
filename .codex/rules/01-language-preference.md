# Language Preference Rules

## 1. 기본 언어: 한국어
- 모든 사용자 응답, 진행 상황 보고, 질문, 설명은 **한국어**로 작성합니다.
- 특히 아래의 산출물(Artifacts)은 반드시 한국어로 기술해야 합니다.
  - **구현 계획** (Implementation Plans)
  - **작업 목록** (Task Lists / Todo)
  - **워크스루 / 작업 상세 설명** (Walkthroughs)

## 2. 기술 용어
- 표준 기술 용어, 라이브러리 명칭, 파일 경로, 변수명은 **영어** 또는 표준 기술 표기법을 유지합니다. (예: `FastAPI`, `React`, `Zustand`, `WebSocket`, `BackgroundTasks`, `uv`)
- 널리 받아들여지는 한국어 번역이 있더라도, 코드 및 개발 컨텍스트에서는 가독성과 명확성을 위해 영어 표기를 권장합니다.

## 3. 코드 주석
- 코드의 복잡한 로직이나 아키텍처적 의도를 설명할 때는 **한국어 블록 주석** 작성을 선호합니다.
- 간단한 인라인 주석은 영어와 한국어 모두 허용하되, 단일 파일 내에서는 일관된 스타일을 유지해야 합니다.
