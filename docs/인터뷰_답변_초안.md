## 🎯 결과물 관련

**Q. 이번 빌더톤에서 만든 프로덕트를 소개해주세요.**
- **서비스 명**: JobFit (잡핏)
- **한 줄 소개**: 취준생과 이직자를 위한 AI 기반 맞춤형 역량 갭 분석 및 면접 준비 플랫폼입니다.
- **적용 기술**:
  - **Frontend**: React, TypeScript, Tailwind CSS
  - **Backend**: FastAPI, Python 3.12, Playwright (JD 스크래핑)
  - **AI/ML**: NVIDIA NIM (Llama-3.1-70B, Llama-3.2-90B Vision), ElevenLabs WebSocket API

**Q. 아이디어는 어떻게 시작됐나요? 문제 인식을 하게 된 과정이 궁금합니다.**
- 수많은 채용 공고를 보면서 “현재 내 이력서로 이 회사에 지원해도 될까?”, “부족한 점은 무엇일까?”를 파악하는 것이 매우 어렵고 시간이 많이 드는 작업이라는 것을 느꼈습니다. 구직자가 자신의 이력서와 원하는 공고(JD)만 넣으면 AI가 이를 비교 분석하여 필수 역량과의 차이를 직관적으로 보여주면 좋겠다는 아이디어에서 출발했습니다.

**Q. 짧은 시간 안에 이 정도의 완성도 높은 서비스를 만들기 위해 생각한 핵심 전략은 무엇이었나요?**
- 기술 복잡도를 낮추고 최적의 AI API를 조합하는 것이었습니다. 이력서 파싱은 NVIDIA의 강력한 Vision-Language Model에 맡기고, 실시간 양방향 면접 등 고난이도 기능은 ElevenLabs의 WebSocket API를 활용해 개발 비용을 최소화하면서도 사용자 경험을 극대화하는 데 집중했습니다.

**Q. 이번 프로젝트에서 활용한 핵심 AI 기술은 무엇인가요? 해당 기술을 선택한 이유는 무엇이었나요?**
- 핵심 기술은 **NVIDIA의 Llama-3.2-90B Vision 모델**과 **ElevenLabs의 실시간 음성 AI**입니다. Vision 모델은 복잡한 양식의 PDF 이력서를 정확하게 파싱하고 구조화하는 데 탁월한 성능을 보였기 때문이며, ElevenLabs는 자연스러운 양방향 한국어 대화가 실시간 수준(WebSocket)으로 가능해 면접 모의고사 기능에 가장 적합했기 때문입니다.

**Q. Anthropic, NVIDIA, ElevenLabs, Replit 의 기술을 사용하셨다면, 구현 단계 중 어떤 단계에 어떻게 적용하셨나요?**
- **NVIDIA**: 사용자가 업로드한 이력서(PDF/이미지) 내용을 이해하고 구조화된 JSON 형태로 추출하는 파싱 단계, 그리고 JD의 요구사항과 이력서 스킬을 비교하는 갭(Gap) 분석 단계에 활용했습니다.
- **ElevenLabs**: AI 모의 면접 기능에서 사용자의 음성을 인식하고 AI 면접관의 목소리를 실시간 스트리밍으로 생성하여 지연 없는 대화 인터페이스를 구현하는 데 적용했습니다.
- **Replit**: 복잡한 인프라 설정 없이 빠르게 프로젝트를 배포하고 테스트하는 환경으로 활용했습니다.

**Q. 기술적으로 가장 도전적이었던 부분이 있었던 부분과 극복하신 방법이 궁금합니다!**
- JS로 렌더링되는 다양한 채용 사이트의 공고(JD)를 안정적으로 스크래핑하는 것과, 브라우저 환경에서 ElevenLabs 보이스 스트리밍을 구현하는 부분이 어려웠습니다. 스크래핑은 Playwright를 폴백으로 두어 해결했고, 음성 통신은 WebSocket을 직접 제어하며 최적화하여 지연 시간을 줄였습니다. 

**Q. 사용한 기술이 완성도에 어떤 차이를 만들었나요?**
- NVIDIA Vision 모델 덕분에 별도의 OCR 파이프라인 우회 없이, 이미지 형태의 이력서까지 한 번에 높은 정확도로 처리해 압도적인 시간 단축을 이루어 냈습니다. 또한 ElevenLabs의 실시간 스트리밍은 단순 챗봇을 넘어 실제 면접을 보는 듯한 탁월한 사용자 몰입형 경험을 만들어주었습니다.

- [예시 답변: Cursor나 GitHub Copilot과 같은 AI 코딩 어시스턴트 활용을 더 고도화하는 방법, 또는 RAG 아키텍처를 좀 더 심도 있게 공부하여 이력서 분석의 맥락(Context)을 더 넓게 잡게 하고 싶습니다.]

**Q. 최근에 눈길이 더 가는 혹은 조금 더 배워보고 싶은 기술이나 툴이 있다면 어떤 것에 주목하고 계신가요?**
- [예시 답변: Agentic AI 기술이나 복잡한 워크플로우를 자동화할 수 있는 LangGraph, AutoGen 쪽에 관심이 많습니다.]

**Q. 나만의 서비스를 만들고 싶지만, 어떻게 시작해야할지 망설이고 있는 분들에게 조언이나 공유하고 싶은 나만의 노하우가 있으실까요?**
- "완벽한 설계보다 일단 동작하는 작은 프로토타입을 만드는 것"을 추천합니다. 요즘엔 프론트부터 백엔드, 배포까지 뼈대를 잡아주는 좋은 서비스와 보일러플레이트가 많기 때문에 핵심 아이디어 하나만 AI API에 연결해 보면 금방 재미를 느끼고 발전시킬 수 있을 것입니다.

## 🚀 해커톤 참여 경험 및 이후 계획

**Q. 저희가 이번 빌더톤 참여자를 모집하면서 ‘누구나 빌더가 될 수 있다’라는 메세지를 계속 전해왔는데, 이 말에 대해 동의하시나요?**
- 강하게 동의합니다. 이전에는 특정 도메인(음성인식, 컴퓨터비전)을 해결하기 위해 엄청난 시간과 전문 인력이 필요했지만, 이제는 API 연동과 프롬프트 엔지니어링만으로 훌륭한 결과물을 낼 수 있기 때문에 누구나 아이디어만 있다면 빌더가 될 수 있는 시대입니다.

**Q. 실제로 빌더톤에 참여하기 전/후로, AI에 대한 생각이나 태도가 달라진 게 있을까요?**
- [예시 답변: 이전에는 AI를 신기한 장난감이나 코딩 보조 도구 정도로만 생각했다면, 이제는 내 서비스의 핵심 코어로서 상용화가 충분히 가능한 기술이라는 확신을 가지게 되었습니다.]

**Q. 빌더톤에 참여하시면서 가장 인상 깊으셨던 부분이 무엇이었나요?**
- 우리 팀뿐만 아니라 다른 훌륭한 참가자분들이 짧은 시간 내에 AI를 활용하여 실생활의 문제를 풀어낸 놀라운 수준의 프로덕트들을 보았을 때가 가장 인상 깊었고 자극이 되었습니다. 

**Q. 빌더톤에서 수상한 MVP를 더 발전시킬 계획이 있으신가요?**
- 네, 현재 JobFit MVP의 핵심 파이프라인이 완성되었으니, 실제 취준생들의 피드백을 받아 이력서 피드백 UI를 고도화하고 로드맵(학습 계획) 추천 및 모의 면접 질문 다양화 등을 추가하여 실제로 런칭해 볼 계획입니다.

**Q. 1년 뒤, 패스트캠퍼스가 AI 가지고 이런 재미있는 프로젝트를 해줬으면 하는 게 있을까요?**
- [예시 답변: 단순 무박 해커톤에 그치지 않고, 우수 프로젝트를 선발해 소규모 시드 투자를 연계하거나 실제 마케팅/런칭까지 인큐베이팅해주는 '초기 창업형 AI 빌더톤'을 기획해주시면 더 재미있고 의미 있는 기회가 될 것 같습니다.]

**Q. 마지막으로, 나는 AI 시대의 ‘빌더’가 맞다?**
- 네, 맞습니다! 주어진 기술을 결합하여 세상에 없는 가치를 만들어내는 과정을 경험했기에, 앞으로도 계속해서 문제를 해결하는 빌더로 성장해 나갈 것입니다.
